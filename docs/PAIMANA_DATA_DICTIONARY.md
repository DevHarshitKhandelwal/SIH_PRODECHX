## 1. Overview & Classification System

This Data Dictionary defines every field identified, derived, or engineered for the PRODECHX platform based strictly on empirical inspection of the official MoSPI PAIMANA Flash Reports. 

Every field in the platform is strictly classified into one of four operational categories:

1. **`SOURCE FIELD`**: Extracted directly from official PAIMANA PDF reports without transformation.
2. **`DERIVED FIELD`**: Calculated via deterministic mathematical, temporal, or logic transformations on one or more `SOURCE FIELD`s.
3. **`ML FEATURE`**: Processed, normalized, or aggregated inputs prepared specifically for Machine Learning model feature matrices.
4. **`ML PREDICTION`**: Output generated by trained Machine Learning models (or SHAP explainability routines).

## 3. Derived Fields (Calculated Deterministically)

| Field Name | Data Type | Formula / Logic | Field Classification | Description |
|---|---|---|---|---|
| `cost_overrun_amount` | Decimal(15,2) | `GREATEST(0, revised_cost - original_cost)` | **DERIVED FIELD** | Absolute cost escalation in Rs. Crore over approved cost. |
| `cost_overrun_pct` | Decimal(5,2) | `((revised_cost - original_cost) / original_cost) * 100` | **DERIVED FIELD** | Percentage increase in project cost relative to original cost. |
| `financial_progress_pct` | Decimal(5,2) | `(cumulative_expenditure / COALESCE(revised_cost, original_cost)) * 100` | **DERIVED FIELD** | Financial progress percentage based on cumulative expenditure vs total cost. |
| `schedule_delay_months` | Integer | `MONTHS_BETWEEN(COALESCE(revised_doc, original_doc), original_doc)` | **DERIVED FIELD** | Months of schedule slippage between original and current completion date. |
| `approved_duration_months` | Integer | `MONTHS_BETWEEN(original_doc, start_date)` | **DERIVED FIELD** | Baseline planned timeline duration in months. |
| `time_elapsed_months` | Integer | `MONTHS_BETWEEN(report_date, start_date)` | **DERIVED FIELD** | Number of months elapsed from project start to reporting date. |
| `time_elapsed_pct` | Decimal(5,2) | `(time_elapsed_months / approved_duration_months) * 100` | **DERIVED FIELD** | Percentage of original planned schedule time that has elapsed. |
| `physical_financial_gap` | Decimal(5,2) | `financial_progress_pct - physical_progress_pct` | **DERIVED FIELD** | Discrepancy between funds spent % and physical work completed %. High gap indicates expenditure anomaly. |
| `monthly_progress_velocity` | Decimal(5,2) | `(physical_progress_pct_t2 - physical_progress_pct_t1) / delta_months` | **DERIVED FIELD** | Measured rate of physical progress per month across sequential monthly reports. |
| `expenditure_burn_rate` | Decimal(15,2) | `(cumulative_expenditure_t2 - cumulative_expenditure_t1) / delta_months` | **DERIVED FIELD** | Measured monthly expenditure rate in Rs. Crore between consecutive reports. |
| `data_quality_score` | Integer | `100 - (penalty_missing_dates + penalty_invalid_costs + penalty_anomalies)` | **DERIVED FIELD** | Automated score (0-100) reflecting completeness and logical consistency of extracted project record. |

## 5. ML Predictions & Explainability Outputs

| Field Name | Data Type | Model Type | Field Classification | Description & Target Range |
|---|---|---|---|---|
| `pred_cost_overrun_prob` | Float | Binary Classification (XGBoost/LightGBM) | **ML PREDICTION** | Model-estimated probability (`0.00` to `1.00`) that project will exceed current revised cost. |
| `pred_cost_overrun_pct` | Float | Regression (RandomForest/XGBoost) | **ML PREDICTION** | Predicted additional percentage cost overrun at completion. |
| `pred_final_cost` | Decimal(15,2) | Derived from ML Regression | **ML PREDICTION** | Estimated final project cost at completion in Rs. Crore (`revised_cost * (1 + pred_cost_overrun_pct/100)`). |
| `pred_delay_prob` | Float | Binary Classification (XGBoost/LightGBM) | **ML PREDICTION** | Model-estimated probability (`0.00` to `1.00`) of further schedule completion delay. |
| `pred_delay_months` | Float | Regression (LightGBM/Statsmodels) | **ML PREDICTION** | Predicted additional completion delay in months beyond current Revised DoC. |
| `pred_expected_completion_date` | Date | Derived from ML Delay Regression | **ML PREDICTION** | Calculated expected final operational completion date (`revised_doc + pred_delay_months`). |
| `composite_risk_score` | Integer | Configurable Risk Formula / Model Score | **ML PREDICTION** | Normalized overall project risk score (`0` to `100`). Categorized into `LOW` (0-29), `MODERATE` (30-49), `HIGH` (50-74), `CRITICAL` (75-100). |
| `shap_feature_importance` | JSONB | SHAP Explainability Engine | **ML PREDICTION** | Top SHAP feature contribution values explaining the exact quantitative drivers for a project's risk score. |
